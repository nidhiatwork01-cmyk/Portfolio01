## ⚡ Motion & Interactions

1. **Terminal Calibration Preloader:** Sequential boot simulation tracking module hydration before smooth unmasking.
2. **Context-Aware Magnetic Cursor:** Dynamic spring ring that expands with context badges (`"VIEW"`, `"INSPECT"`, `"COPY"`, `"LIVE"`). Gracefully disables on touch devices.
3. **Interactive Background Canvas:** Velocity-reactive particle mesh that repels and warps around cursor position in real-time.
4. **Live Telemetry Top Bar:** Real-time Indian Standard Time (IST `UTC+5:30`), live frame rate monitor (FPS counter), and Web Audio synthesis toggle.
5. **Interactive Audio Feedback:** Pure Web Audio API tactile synthesizers (clicks, warps, blips, success chime) — zero audio files, 0ms latency.
6. **Dual-Mode Project Showcase:**
   - **3D Tilt Deck:** Interactive perspective card hover tilt, quick metric badges, and instant modal case study launcher.
   - **Systems Matrix:** Dense technical engineering console table with instant category filtering.
7. **Expandable Case Study Modal:** Deep technical breakdown with system metrics, live demo launchers, and GitHub source links.
8. **Interactive Skills Telemetry Inspector:** Category tabs with animated proficiency bars and clickable nodes revealing real-world production deployment context.
9. **Scroll-Driven Experience Rail:** Glowing timeline nodes connecting HighRadius, WhatBytes, MagicTeal, and Sellar with direct verification links.
10. **Global Command Palette (`⌘K` / `Ctrl+K`):** Fast keyboard-driven search and navigation across all sections, projects, external profiles, and actions.
11. **Interactive Cyber Contact Terminal:** Dispatch message composer, live character count, and one-click email copy with a **confetti celebration burst**.

## 🛠 Tech Stack

- **Framework:** Next.js 15 (Turbopack, App Router)
- **Language:** TypeScript 5+ (Strict Mode, 0 `any`)
- **Styling:** Tailwind CSS + PostCSS
- **Animation:** Framer Motion (Spring physics, exit animations)
- **Icons:** Lucide React + Bespoke SVGs
- **FX:** Canvas Confetti + Web Audio API Synthesizer

## 💻 Local Setup & Development

### Prerequisites
- Node.js `v18+` (v20+ recommended)
- npm or pnpm

### Run in Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Run Production Bundle
```bash
npm run build
npm run start
```
